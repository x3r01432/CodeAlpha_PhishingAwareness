# CodeAlpha_PhishingAwareness

**CodeAlpha Cyber Security Internship — Task 2: Phishing Awareness Training**

A 10-slide training presentation that teaches employees how to recognize, avoid, and report phishing attacks, ending with a 5-question self-assessment quiz.

## Contents
- `Phishing_Awareness_Training.pptx` — the training deck.

## Topics covered
1. Title — *Spot it. Stop it. Report it.*
2. What phishing is and why it works.
3. Five phishing channels: email, spear, smishing, vishing, clone.
4. Six red flags that give most phishing away.
5. Anatomy of a phishing email (annotated example).
6. What to do and what not to do.
7. How to report in three steps.
8–10. "Is it phishing?" scenario quiz with an answer key and the three golden rules: **Stop, Think, Report.**

All examples use fictional names and reserved/example domains; the content is defensive security awareness only.
